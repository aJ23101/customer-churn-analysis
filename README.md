# Customer Churn Analysis

## Overview

This project analyzes customer churn using Python and SQLite to identify factors influencing customer retention.

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- SQLite
- Jupyter Notebook

---

## Project Workflow

- Data Collection
- Data Cleaning
- Exploratory Data Analysis
- Data Visualization
- Business Insights

---

## Project Files

- churn_analysis.ipynb
- customer_churn.db
- customer_churn_data_raw.xlsx
- report/churn_analysis_report.pdf

---

## Key Insights

- Customers with month-to-month contracts are more likely to churn.
- Monthly charges influence customer retention.
- Customer tenure is an important predictor of churn.
